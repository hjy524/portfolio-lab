# 资产配置工具箱课堂演示指南

建议演示约 5–8 分钟。第一轮展示基本流程，第二轮邀请模拟投资人提出限制，并直接修改参数。

## 基本流程

1. 在第一步说明所有示例资产和数据均为模拟；输入统一年化，收益率使用百分数展示。
2. 保留六种资产，进入第二步。默认使用均值–方差效用，风险厌恶系数为 4，允许配置无风险资产。
3. 生成方案。解释权重、金额、预期年收益、年化波动和夏普比率；展示每项限制的核对。
4. 打开投资机会集，指认可行组合样本、最小方差边界、有效前沿、全局最小方差点、最大夏普风险组合与 CAL。
5. 用样本滑块查看任一组合的权重，说明散点是可行集的样本。
6. 下载 JSON 和报告，在专业分析中展示相关性与协方差。

## 五个模拟投资人场景

| 场景 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 只接受低风险 | 目标改为尽可能降低波动，保留现金 | 全部现金、零波动、夏普不适用 |
| 不愿全放现金 | 设置现金上限 20%，目标仍为最低波动 | 风险资产权重至少 80%，重新出现非零波动 |
| 不想投股票太多 | 开启类别限制，将权益上限设为 40% | 权益净权重合计不超过 40%，有效前沿改变 |
| 提出不可能的要求 | 每项风险资产最高 10%，现金上限 10% | 最高比例之和不足 100%，工具明确说明不可行 |
| 接受借款 | 现金最低 −20%，总敞口 140%，降低风险厌恶 | 工具可使用借款；同时检查实际总敞口，不保证一定借款 |

再关闭无风险资产开关，展示仅风险资产的完整最小方差边界及有效分支，强调下方分支是方差最小但被更高收益组合支配的部分。

## 常见问题

**为什么最低波动方案全是现金？** 现金在模型里方差为零。如果投资人不接受，可设置现金最高比例，或关闭无风险资产。

**为什么金色 CAL 只有部分可投资？** 风险组合和现金混合后，单项比例、类别、现金或总敞口限制可能被违反。只有逐点通过检查的部分画为实线；真正的受约束前沿另行优化。

**为什么说是预期收益？** 这来自手工假设或历史样本估计，不保证未来表现。工具用于比较给定假设下的配置选择。

**能否用自己的数据？** 支持简单收益率 CSV，第一步有模板。价格需要先转换为同频、同币种、已对齐的简单收益率；本工具不自动下载或清洗行情。

**如何解释风险厌恶系数？** A 越高，同样的预期收益下越不愿承担方差。该输入用于展示均值–方差选择，不等于已测量投资人的真实心理偏好。

## 使用检验记录

每次测试记录投资人的原话、输入限制、任务是否完成、遇到的困惑与修改建议。可比较两轮中“从打开工具到获得可解释方案”的耗时、是否需要口头帮助以及限制错误提示是否可理解。不要把示例收益当成真实投资业绩。
