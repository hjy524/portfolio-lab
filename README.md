# 配比 Portfolio Lab

[打开在线演示](https://portfolio-lab-midpxwpwqgw53xirwcmhta.streamlit.app/) · [GitHub 源码](https://github.com/hjy524/portfolio-lab)

用于资产定价课程的 Python 资产配置 Demo。入口分为**普通用户**与**专业用户**：普通用户回答日常语言的问题，专业用户可自行编辑参数、投资限制和协方差假设。两种模式使用相同优化方法。

默认提供**中国上市 ETF 的真实历史数据**，统一人民币计价，含股票、国债和黄金 ETF。真实数据快照附来源、获取时间、实际起止日期和校验值，可在线刷新；接口失败时明确保留已验证的真实快照，不会偷偷换成模拟数据。另保留模拟资产与历史收益 CSV 导入，均明确标识。无需证券账户或 API 密钥。

## 新版结果总览

“方案总览”把我的方案、最小方差方案、切线／最大夏普风险组合集中比较；允许现金时还列出仅风险资产最小方差组合，避免全现金方案掩盖课程要求的风险资产配置。

每项方案均展示预期年收益、年化波动、夏普比率、最大仓位资产及证券代码，附一句话解读。类别配置图、类别权重表和逐证券权重对照让结果可直接比较。可下载方案汇总、持仓对照 CSV、完整参数 JSON 和包含全部方案的演示报告。风险组合参考值与含现金的整体方案分开标识。

## 普通用户如何选择

先了解股票、债券、黄金等类别各意味着什么，再回答本金、可能用钱的时间、对上下起伏的偏好与最低现金比例。工具会先展示翻译后的规则：年化波动上限、现金底线、股票与另类资产上限、单只 ETF 最多 40%、不做空、不借款。近期可能用钱时提高现金底线并降低股票上限；这些是公开的课堂演示规则，不是正式的个人风险测评。

普通用户不会被要求输入相关系数或风险厌恶系数。专业模式保留这些设置；切换为普通模式后需重新确认普通模式的偏好，避免沿用隐藏的做空或借款设置。

## 真实行情口径

候选池：510300 沪深300ETF华泰柏瑞、510500 中证500ETF南方、513500 标普500ETF博时、511010 国债ETF国泰、511260 十年国债ETF国泰、518880 黄金ETF华安。这里列出的是用于课堂分析的候选证券，未接入实际下单或账户持仓。

主来源为 Yahoo Finance 的人民币复权收盘价，备用为东方财富前复权收盘价。每次整组获取使用同一来源，不混用未经复权的价格。排除上海日期的当天盘中数据，将共同交易日先对齐再计算简单收益，不前向填补缺失价格；至少需要 120 个对齐日收益观测。可选择 1、3、5 年窗口；刷新成功前不会把旧快照假称为新窗口。

仓库内真实快照截止 **2026-10-23**，起始于 **2023-10-25**，共 **724** 个日收益观测。日期会随主动刷新更新，网页始终显示实际截止日；超过 15 天会提示。预期年收益使用历史日均值 ×252，协方差使用日样本协方差 ×252，不是收益预测保证或组合回测结果。专业用户修改假设后会另行标识。

国债 ETF 有价格波动，不是模型无风险资产；标普500ETF 虽用人民币交易，仍有海外股票、汇率和折溢价风险。现金基准利率由用户假设，不冒充实时银行利率，也不伪造证券代码。

维护者可运行 `python scripts/update_market_snapshot.py` 显式更新并校验仓库快照。网页刷新仅更新当前服务内的行情，不自动修改 GitHub 文件。更多来源与证券说明见 [数据说明](data/README.md)。

## 本地使用

使用 Python 3.10 或 3.11。在项目目录中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m streamlit run app.py
```

打开终端显示的本地网址，通常是 `http://localhost:8501`。如果当前 Python 已安装依赖，可直接双击 `start.bat`。关闭运行窗口即可停止。

macOS / Linux 使用 `.venv/bin/python` 替代 `.venv\Scripts\python`。

## 使用流程

1. **选择入口和资产**：先选普通／专业模式。普通模式解释资产类别；专业模式可启用或关闭资产、编辑假设。真实 ETF 的名称与代码固定；模拟和导入模式可新增资产。相关矩阵必须对称、对角线为 1、半正定。
2. **设置目标与限制**：选择均值–方差效用、最低波动、目标收益、波动上限或最大夏普目标。设置单项权重上下限、类别净权重上下限、无风险利率、现金上下限、做空与总敞口。
3. **查看配置方案**：先在方案总览对比各组合的风险收益、最大仓位、代码与权重，再查看我的资金清单、限制检查、可行组合样本、两类前沿与切点参考。图表支持悬停、缩放；样本滑块可查看各组合的权重。
4. **导出与复现**：下载配置清单、前沿、可行样本 CSV、输入结果 JSON 与课堂演示报告。运行 `python reproduce.py allocation_snapshot.json` 可复算 JSON。

## 历史数据导入

CSV 第一列名为 `date`，后续每列是一项资产。每行是同一期间的**简单收益率小数**，不是价格；例如 1% 输入 `0.01`。支持月度、周度、日度频率。至少 24 期观测、2–12 项资产，无缺失值，日期唯一且从早到晚排序。第一步可下载完整格式示例，也可使用 `examples/monthly_returns.csv`。

```csv
date,资产A,资产B
2020-01-31,0.012,-0.003
2020-02-29,-0.020,0.005
```

上面两行仅说明格式，不满足至少 24 期的要求。工具不会默默补齐、删除或前向填充缺失数据。频率由用户确认，不自动推断；跨期不相关和平稳是年化所需的假设。

预期年收益使用算术均值乘年内期数，协方差使用样本协方差乘年内期数；波动为年化协方差对角线的平方根。该预期收益不是 CAGR。样本奇异或重复资产会提示修正。CSV 仅在当前服务进程内处理，本应用不主动保存到磁盘或数据库。

## 计算口径

令 `w` 为权重、`μ` 为预期年收益向量、`Σ` 为年化协方差矩阵：

- 组合预期收益：`wᵀμ`；波动：`sqrt(wᵀΣw)`。
- 预算：`sum(w) = 1`。禁止投资可令该项上下限均为 0，固定持仓可令上下限相等。
- 总敞口：`sum(abs(w)) ≤ L`，包括无风险资产。例如 120% 股票和 −20% 现金意味着总敞口 140%，不是 120%。
- 类别上下限按组内**净权重**计算；做空会抵消同组多头。无风险资产使用独立现金上下限。
- 目标收益与波动上限作用于推荐方案；机会集和前沿始终展示全部满足持仓限制的组合。
- 可行性先用线性规划判断。允许做空时，通过辅助变量将绝对值总敞口约束转为线性约束。
- 最小方差边界：在可达收益区间取目标收益网格，每个点求解凸二次规划。保留最小方差组合下方的分支；有效前沿选取其上方分支。
- 最大夏普：若存在正超额收益组合，采用凸透视变换，令 `y=t·w`，固定 `(μ-rf)ᵀy=1`，最小化 `yᵀΣy`，同时缩放全部线性限制，再恢复 `w=y/t`。不使用可能陷入局部解的比值直接优化。
- 均值–方差效用：最大化 `wᵀμ − A·wᵀΣw/2`。该系数来自用户选择，不是工具估计的个人偏好。
- 可行散点采用固定随机种子的 hit-and-run 采样；有限散点**不是完整可行集**。极窄的可行集可能显示更少样本，边界单独通过优化求解。
- 所有成功优化结果都会检查预算、上下限、类别限制和总敞口。权重容差为 `2e-6`，即 0.0002 个百分点；目标收益或波动上限也会检查。

### 无风险资产与 CAL

无风险资产方差、与其他资产的协方差均为零。开启无风险资产后，工具直接扩展资产集合、重新优化所有组合，不把理论直线直接当作可行前沿。若允许 100% 无风险资产，全局最小方差应为零波动；其夏普比率显示为不适用。

仅风险资产的最大夏普组合用于构造 CAL 理论参考线。标准假设下是切点组合；有约束时可能位于角点。图中另用实线标注该参考线上满足全部实际投资限制的部分。存在单项持仓下限、类别限制、现金限制或杠杆上限时，CAL 的可行部分不一定与受约束有效前沿重合；有时风险资产单独满仓投资也不可行，此时明确提示，不捏造切点。

借款与存款共用无风险利率，暂不考虑保证金追缴、税费、交易成本、整数手数、汇率预测、多期再平衡与现金流。风险衡量是标准差，不是最大回撤；目标收益也不是收益保证。

| --- | --- |
| 投资者决定输入、识别可投资产 | 资产编辑器、启用选择、新增资产、CSV 导入 |
